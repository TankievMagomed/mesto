## Верстка адаптивного сайта с применением JS

Это интерактивная страница, куда можно добавлять фотографии, удалять их и ставить лайки, а её реализация демонстрирует освоенные возможности HTML CSS, JS (реализована форма корректировки имени и информации о пользователе ![на обычном экране](./images/screenshot_4.png) и ![мобильном устройстве](./images/screenshot_5.png)), и адаптивной верстки.


### Технологии:

- HTML 5
- CSS 3
- JS
- Flexbox
- Grid Layout
- Media
- БЭМ nested
